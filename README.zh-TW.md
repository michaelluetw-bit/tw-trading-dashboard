# 衡析 EquiLens｜台股看盤與交易研究儀表板

盤中熱浪圖選用 Shioaji 時沿用既有最多 200 檔訂閱，顯示研究範圍、已確認／計畫訂閱數、有效普通股報價數、報價時間與斷線狀態；不新增訂閱或查詢永豐金快照。全市場盤後及歷史查詢保留，時光機錄製仍需快照來源。

**架在自己電腦上的台股看盤、當沖監控與籌碼研究戰情室（tw-trading-dashboard）。** 衡析在你的電腦上執行，從開盤前的焦點新聞、盤中的即時監控與提醒，到盤後的籌碼追蹤與 AI 日報，
都在同一套系統裡完成，手機也能隨時查看並收到推播。資料來源與 API 金鑰由你自己準備，資料不會送到其他地方。

## 組成

| 元件 | 說明 | 預設網址 |
|---|---|---|
| **衡析 Nexus**（`EquiLens-Nexus/`） | 電腦版，也是唯一的資料引擎：所有資料都由它取得、計算與保存，排程也都在這裡執行 | http://127.0.0.1:4330 |
| **衡析 Pocket**（`EquiLens-Pocket/`） | 選用的手機網頁版（PWA），資料一律向 Nexus 取得；以密碼保護，透過你選的通道從手機連回；負責推播通知 | http://127.0.0.1:4340 |

兩個服務都只綁定 `127.0.0.1`。**電腦必須開機、Nexus 在執行**，盤中監控、提醒與排程才會運作；手機關閉時推播照常發送。

## 一天的流程

衡析的功能依台股的一天排列如下（其他市場依該市場的交易時段）。標示「自動」的項目由 Nexus 依排程執行，不需要開著頁面。

| 時間（台股） | 衡析在做什麼 | 在哪裡看 |
|---|---|---|
| 開盤前 | 焦點新聞（昨日台股收盤後到今晨美股收盤）、本周經濟數據與科技財報；前一天的 AI 日報 | 今日焦點 |
| 開盤前 30 分鐘 自動 | 取得當沖盤前資料（可當沖標的、暫停交易、參考價）；富果即時推播在開盤前 10 分鐘連線 | 盤中雷達 → 當沖 |
| 09:00–13:35 自動 | 每 10 秒取全市場即時快照：即時熱浪圖、時光機每分鐘錄一格、即時看板、異動雷達、**自訂提醒**；有推播來源時雷達與提醒使用 WebSocket；Shioaji 熱浪使用既有訂閱快取 | 資金熱浪、盤中雷達 |
| 收盤後 5 分鐘 自動 | 保存族群排名收盤紀錄；五檔錄製器整理當日紀錄（有設定匯出資料夾時匯出當日 ZIP）；當沖訊號檢討 | 族群排名、盤中雷達 |
| 16:30 自動 | AI 盤後日報（含自選股逐檔短評），完成後推播 | 今日焦點 |
| 18:30 起 自動 | **分點追蹤**：查詢你追蹤的券商分點當日進出，有單日主導或多日吃貨時推播 | 籌碼追蹤 |
| 19:30 自動 | 研究名單的日資料更新（行情、法人、營收等）、熱浪圖、型態選股 | 研究總覽、型態選股 |
| 每週 自動 | **大戶集中度**：集保股權分散表公布後（通常週五）取得新的一週並推播摘要 | 籌碼追蹤 |

開啟[新聞推播](docs/features/news-push.md)時，另會每分鐘掃描研究名單的個股新聞並推播。各項排程的時間與開關都能在介面中調整。

## 功能

以下是每項功能的摘要；每項功能都有一份完整說明（點名稱開啟），索引見 [docs/features/](docs/features/README.md)。

### 開盤前

- **[今日焦點](docs/features/briefing.md)**：盤前焦點新聞（台股另加鉅亨網）、本周經濟數據與科技財報行事曆，頁首顯示最新一份 AI 盤後日報。

  ![今日焦點：頁首的 AI 盤後日報，含分段重點與自選股逐檔短評](docs/images/desktop-report.webp)

### 盤中

- **[資金熱浪](docs/features/heatmap.md)**：以成交金額為面積、漲跌幅為顏色的全市場板塊熱浪圖，盤中每 10 秒更新（資料源沒有全市場行情時以研究族群為範圍）。
  - **時光機**：盤中每分鐘錄一個全市場畫格，保留最近 20 個交易日，可依時間回放熱浪圖並查看板塊輪動。

  ![資金熱浪：面積為成交金額、顏色為漲跌幅的板塊熱浪圖與板塊資金排行](docs/images/desktop-heatmap.webp)
- **[盤中雷達](docs/features/live-radar.md)**
  - **即時看板**：切換自選或任一研究族群，每檔顯示全日走勢、成交量、量比與外盤比；點卡片（或任何介面中的股票）看當日走勢（均價線、族群均價線）、5 分 K／日 K、五檔與成交明細。
  - **異動雷達**：爆量、急拉急殺、漲跌停（觸及／打開／再鎖）、型態股站上進場價、跌破結構防守。監控範圍可選只看自選、自選＋研究名單或全市場。
  - **[自訂提醒](docs/features/price-alerts.md)**：對任何股票設定條件，盤中成立時推播。
    - 條件：價格 ≥ 或 ≤ 某個價位、漲幅或跌幅達幾 %、預估全日量達昨量幾倍（開盤 15 分鐘後才判斷）。
    - 單次提醒觸發後自動停用，可再按 ▶ 重新啟用；重複提醒要等條件解除後再次成立才會再提醒，兩次至少間隔 5 分鐘。
    - 可在盤中雷達頁的「自訂提醒」面板、個股視窗或 K 線視窗設定；手機版在「盤中 → 提醒」與個股頁。最多 200 則。
  - **浮動雷達視窗**：永遠置頂的小視窗，盯盤時不必切回衡析。

  ![盤中雷達：自選股即時看板與異動雷達（爆量、急拉急殺、漲跌停、當沖訊號、自訂提醒、分點追蹤）](docs/images/desktop-radar.webp)

  點任何股票開啟走勢視窗：當日走勢、當日均價線與族群均價線、每分鐘量，另有 5 分 K、日 K、五檔與成交明細。

  ![走勢視窗：當日走勢、均價線、族群均價線與每分鐘量](docs/images/desktop-chart.webp)
- **[當沖監控](docs/DAYTRADE.zh-TW.md)**（台股，FinMind＋富果）：掃描範圍（預設全部研究族群＋自選，可改只掃自選）以最近 30 個交易日的日 K、完整的 60 分 K 與 5 分 K、同時段歷史量，以及即時五檔的連續變化共同確認做多機會；
  三種做多提醒之外，另有多單轉弱與參考停損兩種風險提醒（風險提醒持續到 13:25）。歷史不足、資料過期或推播不完整時暫停確認；收盤後分版本檢討訊號。
  只做提醒，不自動下單，參考停損也不代表實際持倉。詳見 [docs/DAYTRADE.zh-TW.md](docs/DAYTRADE.zh-TW.md)。
  - **[大盤環境紀錄](docs/features/daytrade-market.md)**：每個訊號記下所屬指數（上市對照加權、上櫃對照櫃買）當下的漲跌、近 15 分鐘變化、在日內均價之上或之下，以及個股相對強弱；訊號檢討依順風／中性／逆風與強於／弱於大盤分組比較。只記錄，不影響分數、門檻與推播，用來驗證日後是否需要大盤濾網。

  ![當沖掃描：觀察名單的四層確認、排序分數、參考停損與目前的大盤環境](docs/images/desktop-daytrade.webp)

  ![訊號檢討：各訊號扣除成本後的報酬，以及依大盤環境、相對強弱的分組統計](docs/images/desktop-daytrade-review.webp)
- **[五檔錄製器](docs/features/book-recorder.md)**（富果即時推播）：錄下推播清單與加錄股票的每次五檔變動，盤中依量能換股，收盤後整理並可匯出 CSV。
- **[族群排名](docs/features/group-rank.md)**：研究族群依量能加權漲幅排名（排除低量個股、以 √成交金額加權），收盤後自動保存紀錄，隔日標示名次變動。

  ![族群排名：量能加權漲幅、上漲比例、成交金額與名次變動](docs/images/desktop-grouprank.webp)

### 盤後

- **[AI 盤後日報](docs/features/ai-report.md)**：彙整當日資金板塊、法人與期權籌碼、雷達異動與自訂提醒、型態訊號、籌碼追蹤、焦點新聞與行事曆，
  交給你選擇的 AI 模型（Claude、OpenAI、Gemini 或任何 OpenAI 相容端點，含本機模型）寫成日報。
  - 內容包含：標題與總結、分段重點、值得注意的個股、**自選股逐檔短評**（每檔一則，標示偏多／中性／偏空）、明日觀察與風險提醒。
  - **明日觀察**以投資顧問的角度分析整體市場，依【大盤】【法人籌碼】【期權】【資金面】【國際】【行事曆】分類：
    大盤量價與漲跌家數、三大法人與外資期權部位、選擇權 P/C、散戶小台／微台多空、融資券，以及今晚美國經濟數據（預估值與前值）與重要財報。
    不預測個股明天的走勢；風險提醒與圖卡上的觀察重點也只談整體市場。
  - 可下載 9:16 盤後籌碼整理圖卡；可查看過去 30 天的日報。
  - 日報在 16:30 產生，分點資料約 18:00 才公布，因此日報中的分點進出是前一個交易日的資料。
- **籌碼追蹤**（台股，需要 FinMind Sponsor）
  - **[分點追蹤](docs/features/broker-watch.md)**：最多追蹤 20 個券商分點（可用名稱或代號搜尋）。每個交易日 18:30 後，一次取回每個分點當天在全市場的進出，
    整理成買超／賣超排行，標出你的自選股與研究名單、連續買超或賣超天數、占當日成交量比例，以及最近幾日累計占股本比例。
    每個分點每天只用 1 次 FinMind 請求。個股視窗的主力分點表也會標出你追蹤的分點。兩種提醒（門檻都可在「籌碼追蹤」頁調整）：
    - **單日主導**：淨買超占當日成交量 ≥ 10%，且淨買超金額 ≥ 1,000 萬元。金額門檻用來排除冷門股，避免買幾十張就占一成成交量的情況。
    - **多日吃貨**：最近 5 個交易日累計淨買超占集保總股數 ≥ 0.3%，用來抓持續累積籌碼的分點，比單日大買更不容易被隔日沖誤導。
    當日成交量取自本機熱浪圖或時光機，集保總股數取自每週的股權分散表，不需要額外的 FinMind 請求；累計天數以本機保存的追蹤紀錄計算，剛開始追蹤的前幾天不會判斷吃貨。
  - **[大戶集中度排行](docs/features/big-holders.md)**：依每週股權分散表，比較千張大戶持股比例的 1 週與 4 週變化，搭配股東人數判讀：
    4 週增加 0.5 個百分點以上且股東人數未增加為「籌碼集中」，相反為「籌碼渙散」。可看自選＋研究名單，或全市場普通股（股東 1,000 人以上）的兩端各 60 檔。
    新的一週公布時推播自選與研究名單的集中／渙散摘要。

  ![籌碼追蹤：追蹤分點的當日進出、達提醒條件的股票與自選／研究名單進出](docs/images/desktop-chips.webp)
- **[法人／期貨籌碼](docs/features/flows.md)**（台股＋FinMind）：三大法人買賣超、外資台指期與選擇權部位、個股買賣超排行與分享圖卡。

  ![法人／期貨籌碼：三大法人買賣超、外資台指期與選擇權未平倉分布圖卡](docs/images/desktop-flows.webp)

### 研究

- **[研究總覽](docs/features/research-score.md)**：對你的研究族群裡每檔股票計算四維分數（技術、法人籌碼、話題證據、行業趨勢），附評分依據、缺值處理與有效權重。
- **[個股視窗](docs/features/stock-detail.md)**：日 K 與均線、估值與營收快照、分項診斷、主力分點（近 5 日，含隔日沖分點與主力集中度）、大戶持股週變化、自訂提醒、相關新聞。

  ![個股診斷：綜合分數、四個因子與中期價格結構](docs/images/desktop-detail.webp)
- **[型態選股](docs/features/patterns.md)**：90 個交易日、10 種經典型態，附條件式進場與防守價位；站上進場價與跌破防守會進入異動雷達。

  ![型態選股：全市場型態清單、確認狀態、條件進場與結構防守價](docs/images/desktop-patterns.webp)
- **[市場族群／話題追蹤／自選追蹤](docs/features/groups-watchlist.md)**：自訂族群、人工判讀的事件證據、自選分組。

  ![話題追蹤：人工判讀的事件紀錄，依方向與證據強度計分](docs/images/desktop-topics.webp)

## 手機版

完整說明見[手機版與推播通知](docs/features/mobile.md)。

手機版把電腦版的主要功能整理成 7 個分頁，並負責推播通知。

| 分頁 | 內容 |
|---|---|
| 焦點 | 焦點新聞、本周行事曆、AI 盤後日報（可切換日期、下載圖卡、立即產生） |
| 盤勢 | 今日盤勢摘要、自選、漲跌排行、強勢股與族群、型態訊號、法人 |
| 熱浪 | 即時熱浪圖、時光機回放 |
| 盤中 | 看板、當沖（含大盤環境與訊號檢討）、雷達（含開啟通知）、**提醒**（自訂提醒）、族群排名、雷達設定 |
| 個股 | 研究名單與自選；個股頁含評分、K 線、自訂提醒、主力分點、大戶持股、新聞 |
| 型態 | 型態選股結果 |
| 籌碼 | 法人、**分點追蹤**、**大戶排行**（後兩者需要 FinMind Sponsor） |

![手機版：今日焦點與 AI 日報、盤中看板、當沖、資金熱浪、個股、分點追蹤](docs/images/mobile-overview.webp)

**推播通知**：在「盤中 → 雷達」按「開啟通知」。會推播的項目：

| 項目 | 推播方式 |
|---|---|
| 自訂提醒 | 每則各自推播（一次超過 6 則才合併） |
| 雷達異動 | 一次 4 則以內各自推播，更多時合併成一則摘要 |
| 當沖做多訊號 | 每到整 5 分鐘彙整成一則；轉弱、跌破參考停損等風險提醒立即推播 |
| 個股新聞 | 每則各自推播，點開直接看原文；可設定夜間勿擾 |
| AI 盤後日報、分點追蹤、大戶週報 | 每份一則；分點與大戶點開到「籌碼」分頁 |

iPhone 需 iOS 16.4 以上，並從主畫面開啟衡析才能收到推播。

## 市場與資料來源

一套衡析一次研究一個市場。交易時段（含午休）、時區、價格跳動、漲跌幅限制、漲跌配色、成交量單位與代號格式都依市場設定；
切換市場時，各市場的族群、自選、提醒與紀錄分開保存，切回來就恢復。

支援市場：**台灣、美國、日本、香港、韓國、英國、德國、法國、加拿大、澳洲、新加坡、印度**。

| 資料源 | 市場 | 金鑰 | 提供 |
|---|---|---|---|
| [證交所／櫃買開放資料](https://openapi.twse.com.tw) | 台股 | 免 | 股票清單、交易日曆、日 K、全市場單日行情、法人（全市場逐日）、本益比、月營收 |

## 安裝

### 需求

- **Node.js 22 以上**：https://nodejs.org
- Windows 10／11、macOS 或 Linux
- 至少一個涵蓋你研究市場的資料源（台股可用免金鑰的證交所開放資料）
- 選用：AI 模型的 API 金鑰；手機連線需要 `cloudflared` 或其他通道、反向代理

### 第一次安裝

Windows 可以在專案根目錄雙擊 **安裝衡析.cmd**：會檢查 Node.js、安裝套件、啟動並開啟設定精靈。也可以手動安裝：

```bash
git clone https://github.com/wakin61043/tw-trading-dashboard.git
cd tw-trading-dashboard/EquiLens-Nexus
npm install --omit=dev
```

開啟 http://127.0.0.1:4330，第一次會出現**設定精靈**：

1. 介面語言與研究市場
2. 資料來源：勾選要用的資料源並貼上金鑰（儲存前會先向資料源驗證，並偵測方案等級）
3. AI 模型：服務、金鑰與模型（選用）
4. 研究族群：自行建立、載入該市場的範例族群，或匯入設定檔

完成後按「更新」下載研究族群的歷史資料（可隨時停止、下次續傳）。

### 手機版

```bash
cd EquiLens-Pocket
node scripts/set-password.mjs     # 設定登入密碼，至少 10 個字元（Windows：設定手機密碼.cmd）
./start.sh                        # Windows：啟動衡析手機版.cmd
```

啟動腳本會在需要時一併啟動 Nexus，再依「資料與設定 → 遠端存取」選擇的連線方式開啟對外網址：

| 連線方式 | 說明 |
|---|---|
| 自動（預設） | 有 `EquiLens-Pocket/.local/cloudflared.yml` 時用 Cloudflare 固定網域，否則開臨時網址 |
| Cloudflare 臨時網址 | 隨機的 `https://….trycloudflare.com`，重新啟動通道就會改變 |
| Cloudflare 固定網域 | 透過 Cloudflare Named Tunnel 使用你的網域 |
| 自行處理 | 你用 ngrok、Tailscale Funnel、Caddy、Nginx 等把 https 網址轉到 `http://127.0.0.1:4340` |
| 不對外開放 | 只接受這台電腦本機的連線 |

在手機開啟網址並登入（可保持 30 天），再「加入主畫面」，之後就像 App 一樣全螢幕開啟。各方式的設定步驟見 [EquiLens-Pocket/README.md](EquiLens-Pocket/README.md)。

## 安全設計

- 服務只監聽 `127.0.0.1`；寫入類 API 需要 CSRF 權杖並檢查來源。
- API 金鑰由作業系統保護：**Windows DPAPI**、**macOS 鑰匙圈**、Linux 的 **Secret Service**（沒有時改存僅限本人讀取的檔案）。網頁與 API 不會讀回金鑰。
- 手機版使用 scrypt 密碼雜湊、登入限速、HttpOnly／SameSite Cookie、嚴格的 CSP，以及由你填入的網域組成的主機名稱白名單；手機版送出的每個請求都會再經過格式檢查才轉給 Nexus。
- 電腦版能變更金鑰與所有設定，遠端使用必須經過 Cloudflare Access，Nexus 也會自行驗證每個請求的 Access JWT。
- 資料留在你的電腦。對外連線只有你設定的資料源與 AI 服務、「今日焦點」使用的公開新聞與行事曆，以及推播服務（只傳送通知文字）。

## 常見問題

**研究族群和自選分組有什麼不同？** 研究族群（研究總覽的「＋ 新增族群」）決定哪些股票要評分與每日更新；自選分組（自選追蹤的「管理分組」）只是把自選股分資料夾。「加入自選」選單兩種都會列出：選研究族群會把股票加進該族群並加到自選。詳見[研究族群、自選與話題追蹤](docs/features/groups-watchlist.md)。

**手機收不到推播？** 確認已在「盤中 → 雷達」開啟通知、電腦上的 Nexus 與手機版都在執行；iPhone 需從主畫面開啟衡析。可按「發送測試」確認。

**自訂提醒沒有觸發？** 提醒只在盤中監控執行時比對（需要盤中即時快照或富果即時推播）。單次提醒觸發過一次就會停用，列表上會顯示「已停用」。

**分點追蹤或大戶排行顯示需要 Sponsor？** 這兩項使用 FinMind Sponsor 的資料。本階段不根據用量API猜方案；未核實權限保持停用，重新驗證不保證開通付費能力。

**分點追蹤查不到今天的資料？** FinMind 約 18:00 後才公布當日分點資料。18:30 前按「立即查詢」會查前一個交易日；自動查詢會在 18:30 後每 30 分鐘重試，直到資料公布。

**更新程式後手機網址變了？** 請改用「重新啟動衡析（網址不變）.cmd」，它不會重啟通道；若使用 Cloudflare 臨時網址，只要重啟通道網址就會改變，建議改用固定網域。

## 補充歷史行情

個股診斷可檢視興櫃及股份轉換前的原代號行情，並展開缺日原因與來源。興櫃前日均價不當作開盤價，補充檔與原行情分開保存，不改變既有評分。詳見[補充歷史行情與缺日說明](docs/features/history-supplement.md)。

### FinMind 第一階段資料保護

撤銷憑證以非機密狀態持久停用；方案未知不猜數字等級，付費能力需核實證據。舊原始代用資料不作還原價計分；缺項顯示不可比較，原始行情照常。既有來源順序、16:30日報與19:30更新時間不變。詳見[FinMind憑證與可信還原價](docs/features/finmind-access.md)。
