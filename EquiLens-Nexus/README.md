# 衡析 Nexus（電腦版）

一般報價、自訂提醒與個股日 K 當日補值共用 Shioaji 當日、本次連線且在既有訂閱內的有效行情。斷線或重連等待時清空即時值；當日 K 棒標示暫估，不寫回歷史或取代正式收盤。FinMind 與鉅亨網新聞分別顯示最後成功、最後新文、錯誤與重試時間。

Shioaji 盤中族群排名、即時看板與熱浪共用既有最多 200 檔訂閱。族群排名每 30 秒更新，顯示來源、報價時間、連線狀態與涵蓋差異；無法確認同範圍時不顯示升降名次。看板每 3 秒更新，快照錯誤獨立列示；當沖歷史與資格缺項不因此補齊。

盤中熱浪圖選用 Shioaji 時沿用既有最多 200 檔訂閱，顯示研究範圍、已確認／計畫訂閱數、有效普通股報價數、報價時間與斷線狀態；不新增訂閱或查詢永豐金快照。全市場盤後及歷史查詢保留，時光機錄製仍需快照來源。

衡析的本機研究核心與電腦版介面：研究評分、資金熱浪、盤中雷達、族群排名、型態選股、AI 盤後日報與所有設定。
整體介紹、支援的市場與資料源見專案根目錄的 [README.zh-TW.md](../README.zh-TW.md)。

## 啟動與停止

| | Windows | macOS／Linux |
|---|---|---|
| 安裝套件（第一次） | `npm install --omit=dev` | `npm install --omit=dev` |
| 啟動 | 雙擊 **啟動衡析Nexus.cmd**（或 `Start-Nexus.ps1`） | `./start.sh` |
| 停止 | `Stop-Nexus.ps1` | `./stop.sh` |

網址：http://127.0.0.1:4330（可用環境變數 `PORT` 更改）。需求：Node.js 22 以上。
第一次開啟會出現設定精靈；之後在「資料與設定」修改市場、語言、資料來源、AI 模型與研究族群。

## 資料位置

所有資料都在 `.local/`（或環境變數 `EQUITY_DATA_DIR` 指定的資料夾）：`config.json`、`settings.json`、`groups.json`、
`watchlist.json`、`price-alerts.json`（自訂提醒）、`stocks/`（研究個股行情）、`heatmap-*.json`、`replay/`（時光機）、`alerts-*.json`、`reports/`、`broker-watch/`（分點追蹤，含認購權證進出）、`warrants/`（權證標的對照、行情與分點快取）、`holders-all/`（全市場股權分散表）等。
切換研究市場時，目前市場的資料會移到 `.local/markets/<市場>/`，切回時搬回。

金鑰由作業系統加密保存（Windows DPAPI、macOS 鑰匙圈、Linux Secret Service），頁面與 API 不會讀回。
`.local/` 絕對不要上傳或分享。

## 遠端使用完整電腦版（選用）

手機版的連線方式與網域在「資料與設定 → 遠端存取」設定，步驟見 `../EquiLens-Pocket/README.md`。

電腦版可以變更金鑰與所有設定，因此遠端使用**只支援 Cloudflare Access**，採雙層保護：

1. **Cloudflare Access**：在 Zero Trust → Access → Applications 為你的主機名稱（例如 `nexus.example.com`）建立應用程式，Policy 只允許指定的信箱。
2. **Nexus 自行驗證**每個遠端請求的 `Cf-Access-Jwt-Assertion`（RS256 簽章、簽發者、AUD、有效期限），不符即回 403。

在「資料與設定 → 遠端存取 → 電腦版」填入：允許的網域、Team domain（`your-team.cloudflareaccess.com`）、Application Audience (AUD) Tag（應用程式設定頁的 64 位十六進位值）。
三項都填好才會啟用；本機 http://127.0.0.1:4330 不受影響。同一個網域不能同時給手機版與電腦版使用。
把網域轉到 `127.0.0.1:4330` 的通道可與手機版共用同一個 `cloudflared` 設定檔（在 `ingress` 多加一條規則）。舊版的 `.local/remote.json` 會在第一次啟動新版時自動轉入設定。
