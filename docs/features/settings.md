# 資料來源與設定

衡析的所有設定都在電腦版「資料與設定」頁；手機版只能調整盤中與推播相關的設定。

## 設定頁各區塊

| 區塊 | 內容 |
|---|---|
| 市場與語言 | 研究市場（12 個市場）、介面語言（繁體中文、英文）、漲跌配色（紅漲綠跌或綠漲紅跌） |
| 遠端存取 | 手機版連線方式與網域、推播聯絡信箱、電腦版遠端存取（Cloudflare Access），見 [EquiLens-Pocket/README.md](../../EquiLens-Pocket/README.md) |
| 資料來源 | 勾選啟用的資料源、貼上金鑰（儲存前會向資料源驗證並偵測方案等級）、重新驗證、進階：每項資料指定優先資料源 |
| 推理模型 | AI 服務（Claude、OpenAI、Gemini、OpenAI 相容端點）、金鑰、模型、推理強度 |
| AI 盤後日報排程 | 自動產生時間（預設 16:30）與開關，見 [AI 盤後日報](ai-report.md) |
| 新聞推播 | 見[新聞推播](news-push.md) |
| 研究族群管理 | 新增、改名、刪除、排序族群與成份股，載入範例 |
| 更新與評分 | 每日自動更新時間（預設 19:30）與範圍（全部或只更新自選）、FinMind 請求間隔、四維評分權重 |
| 設定檔 | 匯出族群、自選與各項設定（**不含金鑰**），在另一台電腦匯入 |
| 介面與使用偏好 | 主題（深色、淺色、跟隨系統）、字級、光暈與動畫、提示訊息、開啟時的頁面 |

功能本身的設定在各自的頁面：雷達與當沖（盤中雷達）、[自訂提醒](price-alerts.md)、[分點追蹤與大戶週報](broker-watch.md)（籌碼追蹤）。

## 資料來源

| 資料源 | 市場 | 金鑰 | 提供 |
|---|---|---|---|
| 證交所／櫃買開放資料 | 台股 | 免 | 股票清單、交易日曆、日 K、全市場單日行情、法人、本益比、月營收 |
| FinMind | 台股 | 免費／Sponsor | 日 K 與還原股價、法人、營收、本益比、新聞、股權分散、期貨、融資；Sponsor 另有盤中即時快照、分 K、全市場資料與新聞、券商分點、全市場股權分散表、當沖盤前資料 |
| 富果 Fugle | 台股 | 免費／付費 | 日 K、分 K；WebSocket 即時推播（盤中雷達、自訂提醒、當沖、五檔錄製） |
| [永豐金 Shioaji](shioaji-bridge.md)（行情轉接） | 台股 | 本機通行碼 | 經本機 `sj-quote-bridge` 的即時推播（精簡模式，上限 200 檔，不能下單） |
| Twelve Data | 12 個市場 | 免費／付費 | 股票清單、日 K、即時報價、分 K |
| Alpha Vantage | 美、英、加、德、印 | 免費／付費 | 日 K、報價、新聞情緒、本益比、季營收 |

- 可同時啟用多個資料源，衡析依勾選順序（或進階設定）為每項資料挑選來源；資料源不支援的功能會自動隱藏或改用本機資料。
- 所有 FinMind 請求共用同一條佇列並控制間隔；金鑰失效、額度用完或方案不足時，自動請求會暫停一段時間。
- 金鑰由作業系統加密保存（Windows DPAPI、macOS 鑰匙圈、Linux Secret Service），網頁不會讀回。

## 切換市場

一套衡析一次研究一個市場。切換時，目前市場的族群、自選、提醒、行情與紀錄收進 `.local/markets/<市場>/`，切回來就恢復。
