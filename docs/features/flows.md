# 法人／期貨籌碼

查詢指定日期的三大法人現貨流向、外資台指期與選擇權部位，以及上市、上櫃個股的法人買賣超排行，並可產生分享用的圖卡。

## 在哪裡

- 電腦版：左側選單「法人／期貨籌碼」。
- 手機版：「籌碼」分頁 →「法人」。
- 只在台股並啟用 FinMind 時顯示。

## 內容

| 區塊 | 內容 |
|---|---|
| 三大法人買賣超 | 合計、外資及陸資、投信、自營商（億元） |
| 外資期權部位 | 台指期淨未平倉與增減（和前一個有資料的交易日比較）、多單／空單；選擇權買權、賣權淨額與增減 |
| 選擇權未平倉分布 | 各履約價的買權、賣權未平倉量，標出買權、賣權最大未平倉的履約價；可切換到期月份 |
| 個股買賣超排行 | 上市／上櫃 × 三大法人合計／外資／投信／自營商 × 買超／賣超（普通股，排除 ETF 與權證；單位：張） |
| 分享圖卡 | 白底 9:16 圖卡，可左右滑動、下載 |

## 查詢方式

- 選日期後按「查詢 FinMind」（2018-06-05 之後）；只有按下查詢才會發出請求。
- 資料完整的日期會保存，之後按「紀錄」即可直接開啟，不再請求。
- AI 盤後日報產生時，如果當天還沒有紀錄會自動查一次。

## 資料來源

FinMind：`TaiwanStockTotalInstitutionalInvestors`、`TaiwanStockInstitutionalInvestorsBuySell`、`TaiwanFuturesInstitutionalInvestors`、`TaiwanOptionInstitutionalInvestors`、`TaiwanOptionDaily`、`TaiwanStockInfo`。一次查詢約需 1 分鐘（依請求間隔設定）。

**個股法人的備援**：`TaiwanStockInstitutionalInvestorsBuySell` 不指定股票、一次查全市場時需要 FinMind Backer／Sponsor 方案。FinMind 回報錯誤（例如免費方案沒有權限），或沒有查詢日期的資料時，改用證交所「三大法人買賣超日報（T86）」與櫃買中心「三大法人買賣明細」（免金鑰，多 2 個請求）。採用條件：

| 檢查 | 條件 |
|---|---|
| 日期 | 上市、上櫃的回應日期都必須等於查詢日期 |
| 表頭 | 上市 T86 與櫃買的欄位名稱與位置必須符合預期；不符時整個市場不採用 |
| 格式 | 股數必須是整數格式（可含千分位）；空白、Tab、單獨逗號、文字或過大的數字都視為錯誤，不補 0。只檢查股票索引範圍內的股票，範圍外的證券（ETF、權證等）略過 |
| 分類 | 每檔股票的 5 種法人分類（外資、外資自營商、投信、自營商自行買賣、自營商避險）必須各有且只有一列；缺少或重複就不採用 |
| 筆數 | 分市場計算「格式正確、分類齊全的不重複股票 ÷ 股票索引中該市場的檔數」，都必須達 60%（異常警戒線，不代表完整） |
| 錯誤 | 任一市場連線失敗，整批不採用 |

- 採用時，頁面顯示「本次個股法人資料使用證交所／櫃買中心公開資料。」，出處列出兩個來源。
- 不採用時，不產生排行，錯誤訊息寫出 FinMind 的原因和每個市場的問題；兩邊都沒有資料時，顯示「非交易日或尚未公布」。
- 部分成功或失敗的結果不保存，下次可重新查詢。
- 外資含外資自營商；自營商為自行買賣＋避險。2026-10-20 實測：上市 1,079 檔、上櫃 761 檔，每檔外資＋投信＋自營商都等於官方「三大法人買賣超」欄。

## 注意事項

- 期貨淨未平倉的增減和「前一個有資料的交易日」比較，不會把缺資料的日子當成 0。
- 部分資料未取得時會標示缺少哪些項目，該日不保存，下次可重新查詢。
