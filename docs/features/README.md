# 衡析功能說明

每項功能各有一份說明，內容包括：在哪裡、怎麼用、運作方式、設定、資料來源與請求量、注意事項。
整體介紹、安裝與日常操作見 [README.zh-TW.md](../../README.zh-TW.md)；各版本的變更見 [版本紀錄](../CHANGELOG.zh-TW.md)。

> 衡析是研究工具。分數、提醒、型態與 AI 文字都是研究紀錄，不是買賣訊號、目標價或報酬預測，也不構成投資建議。

## 盤中

| 功能 | 說明 |
|---|---|
| [資金熱浪與時光機](heatmap.md) | 全市場板塊熱浪圖、盤中每 10 秒更新、每分鐘錄製回放 |
| [盤中雷達](live-radar.md) | 即時看板、異動雷達、浮動雷達視窗、桌面通知 |
| [永豐金 Shioaji 即時行情](shioaji-bridge.md) | 經本機行情轉接服務的即時推播（精簡模式、上限 200 檔、不能下單） |
| [自訂提醒](price-alerts.md) | 個股價位、漲跌幅、預估量條件，成立時推播 |
| [當沖監控](../DAYTRADE.zh-TW.md) | 觀察名單多週期確認的做多與風險提醒（另見[驗證說明](../DAYTRADE-VALIDATION.zh-TW.md)） |
| [當沖大盤環境紀錄](daytrade-market.md) | 每個當沖訊號記下加權／櫃買指數狀態與相對強弱，收盤檢討依順風／中性／逆風分組（只記錄，不影響訊號） |
| [五檔錄製器](book-recorder.md) | 錄下五檔與逐筆成交，收盤後整理並匯出 CSV |
| [族群排名](group-rank.md) | 研究族群的量能加權漲幅排名與收盤紀錄 |
